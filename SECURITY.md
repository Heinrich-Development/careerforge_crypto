# Security

## Scope

This repository holds CareerForge's key hierarchy, its envelope format and a
pure-Dart reference engine. The browser engine the app runs in production,
the CareerForge app itself and its server are not in this repository, but a
report about any of them is just as welcome, at the same address.

## Reporting a vulnerability

Email **support@careerforge.app**, or use GitHub's private vulnerability
reporting on this repository (the **Security** tab, then **Report a
vulnerability**). Please do not open a public issue for anything you believe
is exploitable.

## What to expect

- An acknowledgement within a few working days.
- A fix, or a published statement of why none is needed, before any details
  are made public.

There is no bug bounty programme.
